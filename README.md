## Journal Entry

First, I copied and pasted the HTML and CSS template code into two files I created in a folder called `my first website`: `index.html` and `style.css`. Then, I opened the website in my browser to see what the template looked like. After that, I started looking at the code and figuring out what each line did. For example, if a line displayed text in the title of the website, I could figure out what it did by comparing the code with what I saw on the page. I did the same with the other lines until I managed to display what I wanted.

Then, I opened `style.css`, but I couldn't understand much of it. The only thing I changed was the placeholder colors because I didn't like them. I prefer blue and white, so I changed them.

Adding the image was the hardest part. I copied the line of code provided in the Pixl documentation, but when I opened the website, no image appeared. I realized that the image wasn't on my laptop or hosted on the website. I downloaded an image from the internet and renamed it on my computer. I used that same name in the image code, but it still didn't work!

So, I used AI to find out why my image wasn't showing. This was the question I asked ChatGPT: "Why can't I see the image in this code?"

ChatGPT gave me three options. I learned that I could add images by saving them in the same folder as my project, creating another folder inside the project folder and placing the image there, or using an image URL from the internet.

I really enjoyed this experience because I had never actually worked with HTML before. Well, I had seen it before, but I had never modified it or really understood it. From now on, I will keep learning, and I plan to follow this YouTube course: https://youtu.be/G3e-cpL7ofc?si=JUbj8MPm-1AksDGv.
